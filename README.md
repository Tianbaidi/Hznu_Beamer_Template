# HZNU Beamer 模板（非官方）

> 为了制作幻灯片方便，本模板特地借鉴了 [华中师范大学 Beamer 模板](https://github.com/K-JW/CCNU_BeamerTemplate) 的设计与代码结构，在此向原作者表示感谢。

## 使用说明

1. 安装 TeX Live（推荐完整安装）
2. 下载本模板文件
3. 编写 `.tex` 文件
4. 使用 **XeLaTeX** 编译  
   （已测试：Overleaf 网页版 + Windows 11 + VS Code）
